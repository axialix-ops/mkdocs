# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2025-10-21 - Oracle

### Added
- Integrated CoinGecko API for real-time and historical cryptocurrency data.
- Implemented a cryptocurrency selector on the frontend.
- Created `STATEMENT.md` to describe the project's vision.

### Changed
- Made the trading chart responsive.
- Improved the application startup process and fixed a port mapping issue.

## [0.1.0] - 2023-10-26 - Alpha

### Added
- Initial project structure.
- Basic frontend and backend setup.
- Docker configuration for local development.
