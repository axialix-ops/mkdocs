# Журнал изменений

Все заметные изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и этот проект придерживается [Семантического Версионирования](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2025-10-21 - Oracle

### Добавлено
- Интеграция с API CoinGecko для получения реальных и исторических данных о криптовалютах.
- Реализован выбор криптовалюты на фронтенде.
- Создан файл `STATEMENT.md` с описанием видения проекта.

### Изменено
- График торгов сделан адаптивным.
- Улучшен процесс запуска приложения и исправлена ошибка с портами.

## [0.1.0] - 2023-10-26 - Alpha

### Добавлено
- Начальная структура проекта.
- Базовая настройка фронтенда и бэкенда.
- Конфигурация Docker для локальной разработки.
