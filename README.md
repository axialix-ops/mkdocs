# Симулятор Криптобиржи

Это веб-проект, представляющий собой симулятор криптобиржи с эмуляцией графиков цен и базовым функционалом для торговли.

## 🚀 Особенности

- **Эмуляция реальных данных**: Графики цен генерируются на основе алгоритма, имитирующего реальное движение рынка.
- **Торговый функционал**: Возможность выставлять рыночные ордера на покупку (long) и продажу.
- **Виртуальный кошелек**: Каждый пользователь получает виртуальный кошелек с начальным балансом для торговли.
- **Отслеживание P&L**: Автоматический расчет прибыли и убытков (P&L) по открытым позициям.
- **Веб-интерфейс в стиле TradingView**: Фронтенд, вдохновленный популярными торговыми платформами.
- **API на FastAPI**: Быстрый и современный бэкенд с документацией Swagger.
- **Запуск в Docker**: Весь проект легко запускается с помощью Docker Compose.

## 🛠️ Технологический стек

- **Бэкенд**: Python, FastAPI, SQLAlchemy, Alembic, websockets
- **Фронтенд**: React, Vite, lightweight-charts, axios
- **База данных**: PostgreSQL
- **Оркестрация**: Docker, Docker Compose

## 📦 Установка и запуск

Для запуска проекта на вашем компьютере вам понадобятся установленные **Docker** и **Docker Compose**.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd <название папки>
    ```

2.  **Запустите проект с помощью Docker Compose:**
    ```bash
    sudo docker compose up --build -d
    ```
    Эта команда соберет образы для бэкенда и фронтенда и запустит все необходимые контейнеры в фоновом режиме.

3.  **Откройте приложение в браузере:**
    - Фронтенд будет доступен по адресу: `http://localhost:3000`
    - API бэкенда: `http://localhost:8000`
    - Интерактивная документация API (Swagger): `http://localhost:8000/docs`

4.  **Примените миграции базы данных:**
    Чтобы создать таблицы в базе данных, выполните следующую команду:
    ```bash
    sudo docker compose exec backend alembic upgrade head
    ```

5.  **Запустите генератор рыночных данных:**
    Чтобы начать симуляцию движения цен, необходимо запустить скрипт-генератор:
    ```bash
    sudo docker compose exec backend python app/market_data_generator.py
    ```
    *Примечание: этот процесс будет непрерывно генерировать данные. Вы можете запустить его в фоновом режиме или в отдельном окне терминала.*

## 📝 Описание API

Бэкенд предоставляет REST API для взаимодействия с симулятором. Все эндпоинты, требующие аутентификации, защищены с помощью JWT-токенов.

**Основные эндпоинты:**

- `POST /api/users/register`: Регистрация нового пользователя.
- `POST /api/users/login`: Аутентификация и получение JWT-токена.
- `GET /api/wallet/`: Получение информации о кошельках текущего пользователя.
- `POST /api/trades/orders`: Размещение нового ордера.
- `GET /api/trades/positions`: Получение информации об открытых позициях.
- `WS /ws/prices`: WebSocket для получения обновлений цен в реальном времени.

Подробную информацию о каждом эндпоинте, его параметрах и ответах можно найти в автоматически сгенерированной документации Swagger по адресу `http://localhost:8000/docs`.
